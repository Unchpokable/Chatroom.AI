# Chatroom.AI — План разработки

## Концепция

Приложение-чат с LLM с поддержкой нескольких моделей в одном чате. Гибридный формат:
- Ведущий (пользователь) может писать сам или наблюдать за общением моделей
- Персонам можно редактировать личности
- Ручное управление контекстом и очередью ответов

### Роли в системе

| Роль | Описание |
|------|----------|
| **Ведущий** | Пользователь. Пишет сообщения (role: user), управляет очередью ответов |
| **Персона** | AI-участник. Имеет личность, отвечает (role: user с именем), привязан к LLM-модели |
| **Суммаризатор** | Служебная модель. Не участвует в диалоге, только делает саммари |

## Контекст и история

### Что видит модель при запросе

1. **System prompt** = `PromptBuilder.BuildSystemPrompt(globalPrompt, persona)`
2. **Summary** (если есть) = одно user-сообщение с текстом саммари
3. **History** = `PromptBuilder.FormatHistory(history, format)` — недавние сообщения

### Режимы форматирования истории

| Режим | Формат | Пример |
|-------|--------|--------|
| **XML** | Теги `<from>` | `<from name="Алиса">Привет!</from>` |
| **Scenario** | Префикс `[Имя]:` | `[Алиса]: Привет!` |
| **Messages** | Отдельные user-сообщения с name | `role: user, name: "Алиса"` |

Модели сами теги не пишут — система форматирует автоматически при сборке запроса.

### GlobalSystemPrompt (пример)

```
Ты участник группового чата. В чате несколько участников.
История сообщений размечена тегами <from name="Имя">сообщение</from>.
Отвечай только от своего имени, не говори за других.
```

### project.chatroomai

```xml
<?xml version="1.0" encoding="utf-8"?>
<ChatProject version="1.0">
  <Meta>
    <Name>Мой первый чат</Name>
    <Created>2025-01-20T12:00:00</Created>
    <Modified>2025-01-20T14:30:00</Modified>
  </Meta>

  <Settings>
    <ApiKeyEncrypted>base64...</ApiKeyEncrypted>
    <HistoryFormat>XML</HistoryFormat>  <!-- XML | Scenario | Messages -->
    <DefaultLanguage>Ru</DefaultLanguage>
  </Settings>

  <GlobalSystemPrompt>
    <![CDATA[
    Ты участник группового чата. В чате несколько участников.
    История сообщений размечена тегами <from name="Имя">сообщение</from>.
    Отвечай только от своего имени, не говори за других.
    ]]>
  </GlobalSystemPrompt>

  <Personas>
    <Persona file="personas/alice.xml" />
    <Persona file="personas/bob.xml" />
  </Personas>

  <Summarizer model="openai/gpt-4o-mini" />

  <History file="history/shared.xml" />
  <Summary file="summaries/shared.md" />
</ChatProject>
```

## Заметки

### Важные решения

1. **История как user-сообщения** — чтобы модель не думала, что это её ответы
2. **XML-разметка автоматическая** — модель пишет чистый текст, система оборачивает в теги
3. **Суммаризатор отдельный** — не участник чата, просто инструмент
4. **API-ключ зашифрован** — хранится в файле проекта
